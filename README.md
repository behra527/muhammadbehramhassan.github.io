## Getting Started

**Requirements:** Node.js 20+, npm

```bash
git clone https://github.com/behra527/portfolio.git
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

To create a production build:

```bash
npm run build
npm start
```
